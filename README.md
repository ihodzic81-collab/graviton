# GRAVITON

Mobilna web igra u kojoj se pravila fizike menjaju.
Originalni projekat — HTML5, CSS3, JavaScript (bez biblioteka).

## Struktura

- `index.html` — ulazna stranica
- `manifest.json` — PWA manifest
- `css/` — stilovi (osnova, meniji, igra)
- `js/` — logika (aplikacija, navigacija, pozadina, čuvanje, profil, podešavanja, nivoi)
- `assets/icons/` — ikonice

## Faze razvoja

- **Faza 1 (završena):** temelj, početni ekran, navigacija, čuvanje podataka
- **Faza 2:** igriva osnova — kretanje, gravitacija, sudari, portal, prvi nivo
- **Faza 3:** četiri nivoa
- **Faza 4:** profil i napredovanje
- **Faza 5:** dnevni izazovi
- **Faza 6:** poliranje
- **Faza 7:** buduće nadogradnje (zahtevaju server)

## Pokretanje lokalno

Otvori `index.html` u pregledaču. Za GitHub Pages:
Settings → Pages → Branch: `main` → `/ (root)`.
